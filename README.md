# X Buddy｜投资研究 Agent 工作台

一个可直接在浏览器打开的中文交互式 Web 原型，用来展示个人投资研究 Agent 从目标到可核验报告的主链路。

## 启动

- **最快方式：** 下载并解压，双击 `index.html`，用现代桌面或移动浏览器打开。
- **本地静态服务：** 在本目录运行 `python -m http.server 8000`，访问 `http://localhost:8000`。
- 不需要安装依赖、账号、密钥或后端服务。交互可在浏览器中直接体验。

## 产品选择与核心流程

首页将研究工作映射为一个 Agent run：目标输入 → 模板/规划 → 记忆检索 → 工具调用 → 证据核验 → 确认门 → 研究简报。点击“运行研究”会逐步推进状态；用户可确认或忽略敏感画像记忆、查看事件轨迹和证据链、复制/导出 Markdown 报告。运行轨迹展示子任务、上下文预算、压缩检查点、工具调用、校验事件和等待用户的状态。

设计原则：

- **Harness：** 运行状态、计划步骤、只读工具注册示意、上下文预算、检查点、审批事件和停止状态均可见。
- **研究结果：** 结论区分摘要、论据、风险、验证清单和证据编号；证据链映射主张到来源、时点及核验限制。
- **用户控制：** 涉及用户画像的记忆在本次运行前请求确认；拒绝后本次忽略且不改写长期记忆。产品不执行交易或其他外部写操作。
- **失败处理：** 点击运行卡片中的“演示工具失败与恢复”，可查看超时、缺失字段、检查点恢复和停止规则，并交互演示恢复/停止按钮。生产实现遇到工具超时应限制重试、恢复最近检查点、明确标记缺失/过期证据，并暂停依赖该字段的结论；预算或重试上限到达后停止。模拟演示没有真实 API/故障注入后端。

## AI 与金融数据

此交付是**静态前端演示原型**。没有调用大语言模型、扶摇 API、iFinD MCP 或其他实时行情接口。行情、估值与运行事件均为合成演示数据；页面多处标明“演示数据”，报告不构成投资建议。不能将展示的价格、财务口径或来源摘要用于投资决策。报告里列出的披露来源是演示性来源映射，不代表当前已下载或独立核验了原文。

接入真实数据前，需要后端安全保存凭证、根据扶摇/iFinD实际可用能力注册只读工具，并对每项数据保存原始字段、单位、币种、期间、统计口径、供应方、抓取时间和原文/接口引用。禁止把 API Key 放进浏览器包或公开仓库。模型只应负责规划、归纳与形成带出处的草稿；关键数值校验和权限校验应由确定性逻辑执行。

## 环境变量与边界

当前无环境变量及服务端。待完成的生产化事项：真实数据/MCP 连接器、模型服务端、持久化线程与长期记忆、带租户隔离的授权、服务端审计日志、超时/限流/预算门控、自动化测试、部署和公开产品 URL。原型的“记忆”和运行内容并未持久化到后端。
